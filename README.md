# Python for Biological Image Analysis

Practical proof-of-work from a four-day **Introduction to Python for Image Analysis** course at **ETH Zürich** in July 2026.

This repository documents my progression from Python fundamentals to reproducible biological image-analysis workflows and introductory machine learning.

## Course scope

### Day 1 — Python fundamentals
- Python environments and resources
- Terminal commands
- Object types, loops, and functions
- Python syntax and small runnable exercises

### Day 2 — Biological image analysis packages
- NumPy for matrix manipulation
- pandas for tabular data
- matplotlib and seaborn for visualization
- Opening microscopy formats including TIFF, LIF, ND2, OME-Zarr, and CZI
- OpenCV for image manipulation and introductory computer vision

### Day 3 — Building image-analysis pipelines
- Translating an analysis idea into code
- Working with published code and GitHub
- Moving from raw microscopy images to quantitative data
- Segmentation and tracking
- Morphological measurements
- Fluorescence-intensity quantification
- 2D and 3D colocalization
- Spot counting and foci quantification
- Nuclear-versus-cytoplasmic localization

### Day 4 — Introductory machine learning for image analysis
- Machine-learning fundamentals
- Automated segmentation tools
- Building a simple Python classifier
- Creating a training set
- Model architecture
- Training and validation
- Scaling and parallelization concepts

## Development workflow

Code is developed locally in Visual Studio Code and version-controlled with GitHub.

## Repository structure

- `day01-python-fundamentals/` — Python syntax and small runnable exercises
- `day02-biological-image-io/` — image loading, arrays, tabular data, and basic manipulation
- `day03-image-analysis-pipeline/` — a reproducible quantitative microscopy workflow
- `day04-ml-image-classifier/` — introductory classifier training and validation

The repository will be updated with genuine runnable artifacts as the course progresses.

## Data and research boundary

This public repository does **not** contain unpublished research data or unpublished JM105/Intronsaurus analyses. Course artifacts use course-provided, public, synthetic, or otherwise shareable example data.
